PROJECT OVERVIEW

An AR-based virtual laboratory for engineering practicals

This system lets students perform core physics experiments through realistic, manipulable 3D models rendered directly in the browser — an augmented-reality-style layer of interaction (rotate, zoom, move, control) placed over classic engineering practicals, without needing a physical lab, dedicated hardware, or an AR headset.

Objectives

  • 01
    Develop an AR-based virtual laboratory system for engineering practical experiments and interactive learning.
  • 02
    Design realistic 3D models of laboratory tools and experiment setups for better visualization and understanding.
  • 03
    Implement AR-style technology for real-time experiment visualization and simulation.
  • 04
    Provide interactive features such as zooming, rotation, movement, and virtual experiment control for a better user experience.
  • 05
    Include step-by-step instructions and procedures so students can perform experiments correctly and independently.
  • 06
    Evaluate the system's performance, usability, and educational effectiveness through testing and analysis.

System architecture

The Flask application serves Jinja2-rendered pages and a small JSON API. SQLite3 stores user accounts (with hashed passwords) plus two activity tables — an activity_log that timestamps every experiment interaction, and a feedback table capturing star ratings — which together power the built-in Analytics page used to evaluate usability and engagement (Objective 6). Each experiment page loads a dedicated Three.js scene that reads slider input, recomputes the relevant physics formula, and animates the 3D model and live readouts in real time.
