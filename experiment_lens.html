Step-by-step procedure

  1. Choose Convex or Concave using the lens type buttons.
  2. Set the object distance (u) — how far the object sits from the lens.
  3. Set the focal length (f) of the lens.
  4. Watch the 3D ray diagram: the parallel ray and the central ray locate the image.
  5. Read the Image Distance, Magnification, Nature, and Orientation from the readouts.
  6. Repeat with the object inside and outside the focal length to see the image change.
Rate this experiment:

A convex (converging) lens bulges outward and bends light rays inward towards a focal point, forming real or virtual images depending on object placement. A concave (diverging) lens curves inward and spreads light rays apart, always producing a virtual, erect, diminished image.

1/v − 1/u = 1/f    m = v/u

Using the Cartesian sign convention: distances are measured from the optical centre, the object distance u is negative (object to the left), and the focal length f is positive for a convex lens and negative for a concave lens. A positive image distance v means a real image forms on the far side of the lens; a negative v means a virtual image forms on the same side as the object.

Aim: To study image formation by convex and concave lenses and verify the lens formula by observing how image distance and magnification change with object distance and focal length.

Virtual apparatus: Optical bench, convex/concave lens mount, illuminated object (arrow), screen — all modeled as a manipulable 3D ray-diagram scene.
